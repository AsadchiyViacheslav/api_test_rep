Программная система TikTok

Диаграмма прецедентов:

Авторизованный пользователь (association relationship) -> Смотреть ролик <- (extend relationship) (Поставить лайк, Поделиться, Добавить в избранное, Оставить комментарий)


Авторизованный пользователь (association relationship) -> Просмотреть интересное <- (extend relationship) Выбрать жанр


Авторизованный пользователь (association relationship) -> Начать трансляцию <- (include relationship) Ввести название трансляции



Авторизованный пользователь (association relationship) -> Просмотреть свой профиль <- (extend relationship) (Редактировать профиль, Просмотреть подписки, Просмотреть подписчиков)



Авторизованный пользователь (association relationship) -> Создать публикацию <- (extend relationship) (Выложить, Сохранить в черновик)


Авторизованный пользователь (association relationship) -> Посмотреть диалоги <- (extend relationship) Посмотреть личные сообщения


Авторизованный пользователь (association relationship) -> Отправить сообщение


Авторизованный пользователь (association relationship) -> Посмотреть профиль


Авторизованный пользователь (association relationship) -> Смотреть трансляцию


Авторизованный пользователь (association relationship) -> Смотреть публикации друзей


Авторизованный пользователь (association relationship) -> Найти видео <- (extend relationship) Отфильтровать результат


Авторизованный пользователь (association relationship) -> Просмотреть рекоминдации
